# Quotio project overview

Quotio is a native macOS menu bar app built with Swift 6 and SwiftUI for managing CLIProxyAPI, a local proxy server used by AI coding agents. It supports multiple AI providers, OAuth/account management, quota tracking, fallback routing for virtual models, and CLI agent configuration. The codebase is organized into `Quotio/Models`, `Quotio/Services`, `Quotio/ViewModels`, and `Quotio/Views` with separate components/screens/onboarding subfolders.
